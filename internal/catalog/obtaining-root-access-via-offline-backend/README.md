# Сценарий получения Root через подмену серверов Yandex на свой локальный оффлайн бэкенд

# Для каких колонок подходит?
- Станция 1 (проверено)

# Что необходимо для взлома?
1. Локальная сеть на роутере с отдельной точкой доступа.
2. Для этой локальной сети вы настроили правила firewall на роутере с запретом на маршрутизацию трафика в WAN, разрешаем только в LAN.
3. Вы настроили DNS на роутере:
   1. quasar.yandex.net -> ip вашего устройства
   2. scbh.yandex.net   -> ip вашего устройства
   3. quasar.yandex.ru  -> ip вашего устройства

# Как работает?
1. Генерация quasar sound для подключения колонки к Wi-Fi
2. После успешного подключения колонки к сети колонка проходит этап получения токена и регистрации на локальном сервере
3. Колонка запрашивает обновления и мы выдаем прошивку подходящую под нее для обновления OTA
4. Колонка обновляется, мы переключаем сервер в режим `hasUpdate: false`
5. Колонка обновилась и запрашивает синхронизацию `/sync`, мы отдаем ей настройку с `adb: true` для включения отладки Android
6. Колонка открыла порт adb на `5555` порту
7. Мы подключаемся к колонке по adb и выкачиваем boot.img (boot образ, который запускает ядро системы)
8. Распаковываем boot.img и меняем необходимые нам параметры (включаем adb, добавляем в автозапуск Telnet)
9. Записываем boot.img на колонку и сверяем хэш сгенерированного boot.img и записанного
10. Монтируем boot.img в /boot на колонке и еще раз сверяем хэш
11. Перезапускаем колонку ~~и молимся~~
12. После рестарта на колонке открывается порт Telnet на `2323` порту, подключаемся к нему и ставим dropbear в автозапуск + добавляем публичный ssh ключ, вход по паролю выключаем
13. Удаляем автозапуск Telnet и блокируем правилами firewall доступ к `5555` порту из всех сетей кроме локальной
14. Готово, у Вас root!
